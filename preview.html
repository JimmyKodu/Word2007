Word 2007 桌面应用

功能完整的文档查看和编辑器

实现的功能

📄 文档查看 已实现
  • 支持 .docx 文件（使用 Mammoth.js）
  • 支持 .doc 和 .txt 文件
  • 格式化文本显示（粗体、斜体、下划线）
  • 页面式布局
✏️ 文档编辑 已实现
  • 富文本编辑器（基于 HTML ContentEditable）
  • 格式化工具栏（粗体、斜体、下划线）
  • 字体大小调整（12-32px）
  • 文本对齐（左、中、右）
  • 实时字数统计
💾 文件操作 已实现
  • 新建文档 (Ctrl+N)
  • 打开文档 (Ctrl+O)
  • 保存文档 (Ctrl+S)
  • 另存为 (Ctrl+Shift+S)
⌨️ 键盘快捷键 已实现
  • 标准编辑操作（复制、粘贴、剪切、撤销、重做）
  • 格式化快捷键（Ctrl+B, Ctrl+I, Ctrl+U）
  • 文件操作快捷键
🔒 安全性 已实现
  • 启用 contextIsolation
  • 使用 preload 脚本和 contextBridge
  • 通过 CodeQL 安全扫描（0 警告）
  • 最新的 Electron 版本（无漏洞）

技术栈

  • Electron 40.1.0 - 桌面应用框架
  • Mammoth.js 1.6.0 - .docx 文件处理
  • HTML5 ContentEditable - 文本编辑
  • IPC 通信 - 安全的进程间通信

界面布局

  • 菜单栏：文件、编辑、视图菜单
  • 工具栏：文件操作 | 格式化 | 字体大小 | 对齐方式
  • 编辑区：A4 页面式布局，白色背景
  • 状态栏：文件名显示 | 字数统计
