# Word2007

桌面版 Office Word 查看和编辑器

## 功能特性

- ✅ 文档查看：支持打开和查看 .docx、.doc 和 .txt 文件
- ✅ 文档编辑：完整的文本编辑功能
- ✅ 文本格式化：粗体、斜体、下划线
- ✅ 字体大小调整
- ✅ 文本对齐：左对齐、居中、右对齐
- ✅ 文件操作：新建、打开、保存、另存为
- ✅ 实时字数统计
- ✅ 快捷键支持

## 安装

```bash
npm install
```

## 运行

```bash
npm start
```

## 快捷键

- `Ctrl+N` - 新建文档
- `Ctrl+O` - 打开文档
- `Ctrl+S` - 保存文档
- `Ctrl+Shift+S` - 另存为
- `Ctrl+B` - 粗体
- `Ctrl+I` - 斜体
- `Ctrl+U` - 下划线
- `Ctrl+Z` - 撤销
- `Ctrl+Y` - 重做
- `Ctrl+X` - 剪切
- `Ctrl+C` - 复制
- `Ctrl+V` - 粘贴
- `Ctrl+A` - 全选

## 技术栈

- Electron - 桌面应用框架
- Mammoth.js - .docx 文件处理
- Node.js - 文件系统操作

## 支持的文件格式

- .docx - Microsoft Word 文档
- .doc - 旧版 Word 文档
- .txt - 纯文本文件
